# SHOT APPROVAL GATE

Применяется ко всем storyboard/keyframe assets всех сериалов. Shot может перейти в `APPROVED` только при четырёх PASS одновременно.

## 1. CANON PASS
- персонажи соответствуют canonical model sheet;
- неизменяемые признаки на месте;
- реквизит и локация соответствуют series canon;
- отсутствуют самовольно добавленные элементы мира.

## 2. STORY PASS
- изображено только событие текущего shot-spec;
- нет спойлера более позднего gag/twist;
- нет новой причины, действия, реплики или морали;
- continuity с предыдущим approved shot не нарушена.

## 3. CHARACTER PASS
- возраст, пропорции, костюм, палитра стабильны;
- руки/пальцы/очки/монокли/рюкзаки не дрейфуют;
- персонажи узнаются по силуэту;
- эмоция и поза соответствуют задаче кадра.

## 4. COMPOSITION PASS
- формат и safe area соответствуют платформе;
- главный объект читается на мобильном экране;
- кадр не перегружен случайным foreground;
- крупность и камера выполняют драматургическую задачу;
- оставлено место под субтитры/overlay, если нужно.

## Решение

`APPROVED = CANON PASS + STORY PASS + CHARACTER PASS + COMPOSITION PASS`.

Один FAIL = `REJECTED`. Не «почти подходит», не «поправим в видео». Ошибка исправляется до animation/image-to-video.
