# Series workspace

Здесь хранятся **отдельные творческие пространства каждого мультсериала**.

## Структура

```text
series/
  <Название сериала>/
    README.md
    CANON.md
    STORY_ENGINE.md
    characters/
    scripts/
    storyboards/
    visual/
    assets/
    backlog/
    decisions/
```

### Внутри сериала
- `characters/` — character bible, model locks, характеры, голоса как творческая характеристика;
- `scripts/` — сценарии конкретных эпизодов;
- `storyboards/` — shot-by-shot раскадровки и режиссёрские решения;
- `visual/` — сериал-специфичный визуальный язык, палитра, локации;
- `assets/` — сериал-специфичные manifests и reference requirements;
- `backlog/` — идеи будущих эпизодов;
- `decisions/` — изменения канона и утверждённые творческие решения.

Общие технические правила производства находятся **только** в `/technical/`.
