# REJECTED / NON-CANON

Эта папка предназначена для старых или забракованных визуальных направлений.

## Жёсткое правило

Ни один файл отсюда нельзя использовать как reference для генерации, storyboard, image-to-video или дизайна без отдельного решения в `../../decisions/DECISIONS.md`.

Источником истины является `../../canon/CANON_INDEX.md`.

## Что сюда относится

- ранние варианты Клеппа и Финча;
- ранние character sheets до visual lock;
- варианты Финча с кобальтовой курткой/детскими пропорциями/орнитологией;
- варианты Машины желаний с внутренней кабиной или комнатой;
- альтернативные мастерские и фабричные пространства;
- ошибочные storyboard sheets, добавляющие события не из сценария;
- экспериментальные стили: слишком грубый 2D, слишком плоский 2D, пластиковый 3D;
- любые AI-generated подписи и детали, которые не прошли canon decision.

Сохранение старого варианта для истории не означает его допустимость в production.
